# Приложение «СистемаКонтроля» по работе с строительными объектами - инструкция
### Установка и запуск
1. Скачать архив и распаковать.
2. Перейти в папку backend, ввести команды `npm i` и `npm run dev`.
3. Перейти в папку vue-frontend и ввести команды `npm i` и `npm run dev`.
4. Перейти по ссылке на клиентскую часть в браузер.
